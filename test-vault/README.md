# Vault de prueba

Vault falso con la misma estructura que el real, para desarrollar la app sin tocar tus notas.

- En desarrollo (`npm run dev`) la app arranca apuntando acá.
- Los tests copian esta carpeta a un lugar temporal antes de escribir.
- Lo que genera usar la app (`Sistema/Pomodoro/`) no se sube a Git.

Podés abrirlo en Obsidian ("Abrir carpeta como vault") para ver cómo quedan los registros.
